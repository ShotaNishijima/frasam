# SAMでTMBで実行するためにcppファイルのコンパイル等をする関数

SAMでTMBで実行するためにcppファイルのコンパイル等をする関数

## Usage

``` r
use_sam_tmb(
  TmbFile = "sam2",
  CppDir = system.file("executable", package = "frasam"),
  ...
)
```

## Arguments

- TmbFile:

  Cppファイルの名前

- CppDir:

  Cppファイルが格納されているディレクトリ

## Examples

``` r
if (FALSE) { # \dontrun{
use_sam_tmb()
} # }
```
